# Алгоритм повелительного наклонения

Небольшое русскоязычное учебное веб-приложение: показывает алгоритм образования
форм повелительного наклонения, правила, таблицы и примеры.

## Открыть

- Страница: https://sunpole.github.io/260005-imperative-mood-algorithm/
- Репозиторий: https://github.com/sunpole/260005-imperative-mood-algorithm

## Запуск

Это статическая HTML-страница. Откройте `index.html` в браузере или используйте
опубликованную GitHub Pages-страницу.

## Состав

- `index.html` — интерфейс, стили и учебный материал;
- `VERSION` — версия публичной поставки;
- `CHANGELOG.md` — история изменений;
- `project.json` — паспорт проекта;
- `.github/workflows/deploy-pages.yml` — публикация GitHub Pages.
